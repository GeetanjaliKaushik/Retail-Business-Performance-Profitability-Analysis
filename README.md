Retail Business Performance & Profitability Analysis
* Project Overview:-
This project analyzes retail transactional data to evaluate sales performance, profitability, inventory behavior,
and customer purchasing trends. The objective is to convert raw retail data into meaningful business insights using 
Power BI, SQL, and Python.

* Objectives:-
1. Evaluate overall sales and profit performance
2. Identify high-performing and low-performing categories
3. Analyze yearly sales trends and detect decline patterns
4. Assess inventory efficiency (Fast vs Slow-moving products)
5. Perform correlation analysis between inventory days and profitability
6. Provide data-driven business recommendations

* Tools & Technologies:-
1. Power BI – Dashboard development and data visualization
2. SQL – Data cleaning and query-based analysis
3. Python (Pandas, Matplotlib, Seaborn) – Data processing and correlation analysis
4. CSV Dataset – Retail transaction data source

* Project Workflow:- 
* Data Preparation
1. Imported retail dataset
2. Cleaned and standardized data
3. Created calculated fields:
      a. Sales (Quantity × Price)
]     b. Estimated COGS
      c. Profit
      d. Profit Margin

** Feature Engineering:- 
* Generated Inventory Days metric
* Classified products into Fast-moving and Slow-moving
* Created Overstock Risk indicator

* Data Analysis:-
1. Performed correlation analysis
2. Analyzed category-wise performance
3. Studied payment method distribution
4. Identified customer age-based profit contribution
5. Evaluated sales trends (2021–2023)

* Dashboard Development:-
Developed an interactive Power BI dashboard including:
1. KPI Summary (Sales, Profit, COGS, Quantity, Margin)
2. Sales Trend Analysis
3. Category Performance Comparison
4. Inventory vs Profit Scatter Analysis
5. Movement Type Analysis
6. Payment Method Distribution
7. Dynamic Filters (Year, Category, Mall Location)

* Key Insights:-
1. Clothing is the highest revenue-generating category
2. A significant sales decline is observed in 2023
3. Fast-moving products drive the majority of revenue
4. Some categories show higher inventory holding with lower profitability
5. Customers aged 30–50 contribute higher profit

* Business Recommendations:-
1. Increase focus on high-performing categories
2. Optimize slow-moving inventory
3. Investigate causes of 2023 sales decline
4. Target profitable customer segments
5. Improve payment channel efficiency

* Conclusion:-
This project demonstrates the practical application of data analytics in retail business performance evaluation. 
It highlights how analytical insights can support inventory optimization, profitability improvement, and strategic
decision-making.
